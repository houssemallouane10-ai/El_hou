# مدرّج · Mudarraj

موقع مباريات احترافي: مباريات الأمس واليوم والغد، نتائج مباشرة تتحدث وحدها، توقعات للنتائج، صفحة لكل مباراة فيها مشغل بث بكل الجودات ولغات تعليق متعددة، ومباراة متحركة (أنيميشن) تتبع الاستحواذ والأهداف الحقيقية.

## ما يحتويه الموقع

- **المباريات**: أمس / اليوم / غدًا من 18 بطولة (أبطال أوروبا، الإنجليزي، الإسباني، الإيطالي، الألماني، الفرنسي، روشن، أبطال أفريقيا، الكونفدرالية، المصري…)، مع فلاتر (جارية، لم تبدأ، انتهت) وبحث. التوقيت يظهر بتوقيت الزائر.
- **النتائج المباشرة**: تتحدث كل 30 ثانية، مع تنبيه عند كل هدف وشريط نتائج متحرك في الأعلى.
- **التوقعات**: نسب الفوز والتعادل، النتيجة المتوقعة، أكثر من 2.5 هدف، الفريقان يسجلان، مستوى الثقة. محسوبة بنموذج بواسون من سجل الفريقين هذا الموسم وآخر 5 مباريات. الزائر يقدر يسجل توقعه ويجمع نقاط.
- **صفحة المباراة**: لوحة النتيجة، المشغل، المباراة متحركة، أحداث المباراة، الإحصائيات، التشكيلة، والقنوات الناقلة الرسمية.
- **المشغل**:
  - كل الجودات من 144p حتى 1080p60 مع اختيار تلقائي حسب سرعة الإنترنت، أو اختيار يدوي.
  - لغات التعليق: إذا كان البث فيه عدة لغات يتبدل الصوت بدون ما يتوقف الفيديو.
  - **ما يتقطعش**: يعيد الاتصال وحده عند ضعف الشبكة، يقفز فوق الفراغات في البث، وإذا سقط السيرفر يتحول تلقائيًا للسيرفر التالي من نفس اللغة.
  - وضع توفير البيانات، صورة داخل صورة، ملء الشاشة، وضع السينما، ومعلومات البث (الدقة، السرعة، المخزن المؤقت).
- **القنوات الناقلة**: صفحة فيها beIN SPORTS، Arena Sport، FOX، Sky Sports، DAZN، Movistar Plus+، CANAL+، TNT Sports وغيرهم: اختار منطقتك وتشوف واش تبث كل قناة اليوم وغدًا، مع رابط المنصة الرسمية. نفس المعلومة تظهر في صفحة كل مباراة. الحقوق مكتوبة في `assets/js/channels.js` (موسم 2026-27) وتقدر تحدّثها كل موسم.
- **واجهة بثلاث لغات**: العربية، Français، English. وضع ليلي ونهاري. يخدم على الهاتف والكمبيوتر.

## النشر على الإنترنت (مجانًا عبر GitHub Pages)

1. افتح المستودع على GitHub ثم **Settings ← Pages**.
2. في **Build and deployment** اختر **Source: Deploy from a branch**.
3. اختر الفرع `claude/sports-streaming-site-khngzx` والمجلد `/ (root)` ثم **Save**.
4. بعد دقيقة أو دقيقتين يكون الموقع على:
   **https://houssemallouane10-ai.github.io/Nadouch/**

إذا دمجت الفرع في `main` لاحقًا، غيّر الفرع في نفس الصفحة إلى `main`.

## إضافة روابط البث

البث يقرأ من الملف `streams.json`. حاليًا فيه بثوث تجريبية (فيديوهات مفتوحة) باش تشوف المشغل يخدم بكل الجودات واللغات. لبث مباراة حقيقية أضف روابط **تملك حق بثها** (مثلًا من موزع مرخّص أو من قناتك):

```json
"matches": {
  "real-madrid-vs-barcelona": [
    { "label": "Arabic HD",  "lang": "ar", "type": "hls", "url": "https://.../arabic/master.m3u8" },
    { "label": "French HD",  "lang": "fr", "type": "hls", "url": "https://.../french/master.m3u8" },
    { "label": "Backup",     "lang": "ar", "type": "hls", "url": "https://.../backup/master.m3u8" }
  ]
}
```

- المفتاح هو اسم الفريقين بالإنجليزية بحروف صغيرة وشرطات (`home-vs-away`) أو رقم المباراة في ESPN (يظهر في رابط صفحة المباراة).
- `lang`: `ar`, `fr`, `en`, `es`, `de`, `it`, `pt`, `tr` أو `multi` (بث فيه عدة لغات صوت).
- `type`: `hls` (روابط m3u8)، `mp4`، أو `iframe` (مشغل رسمي مضمّن).
- ضع أكثر من رابط لنفس اللغة: إذا سقط واحد، المشغل يتحول للتالي وحده.
- `leagues` تعطي روابط افتراضية لبطولة كاملة، و`default` لكل المباريات الأخرى.

> لا تضع روابط مقرصنة لقنوات مدفوعة. الموقع مبني ليعرض فقط البث المرخّص.

## تشغيله على جهازك

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الملفات

| الملف | الدور |
| --- | --- |
| `index.html` | الصفحة الرئيسية |
| `assets/css/style.css` | التصميم (ليلي/نهاري، هاتف/كمبيوتر) |
| `assets/js/app.js` | الواجهة والتنقل والتحديث المباشر |
| `assets/js/api.js` | جلب المباريات من ESPN (مع بديل احتياطي) |
| `assets/js/player.js` | المشغل: الجودات، اللغات، التحويل التلقائي بين السيرفرات |
| `assets/js/predict.js` | نموذج التوقعات |
| `assets/js/sim.js`, `pitch.js` | المباراة المتحركة |
| `assets/js/i18n.js` | النصوص بالعربية والفرنسية والإنجليزية |
| `assets/js/config.js` | اسم الموقع وقائمة البطولات |
| `streams.json` | روابط البث |

بيانات المباريات من ESPN. المشغل مبني على [hls.js](https://github.com/video-dev/hls.js) (Apache-2.0).
