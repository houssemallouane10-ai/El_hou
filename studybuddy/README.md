# زميل الدراسة · DZ-StudyBuddy

تطبيق Flutter (Android · iOS · Web) للطالب الجزائري، من الـ BEM إلى الجامعة: المنهاج الرسمي، ملخصات الخمس دقائق، أفضل الشروحات والحوليات، مصحح ذكي لأوراق الإجابة، غرف تركيز جماعية، وبنك صوتيات للمواد الحفظية.

## المراحل الخمس

### 1. التسجيل وملف الطالب
- إنشاء حساب ودخول بالبريد وكلمة السر (Firebase Auth)، مع «نسيت كلمة السر» ورسائل أخطاء بالعربية.
- تعريف في 3 خطوات: الاسم والهاتف (05/06/07، يُحفظ بصيغة `+213…`) والولاية (58 ولاية مع بحث)، ثم المستوى، ثم الشعبة أو الميدان. طالب الـ BEM ينهي بعد خطوتين.

### 2. شجرة المواد الذكية
- **المنهاج الرسمي** في [`assets/curriculum/curriculum.json`](assets/curriculum/curriculum.json): 346 درساً موزعة على الوحدات، لكل مادة معاملها، لـ BEM وكل شعب البكالوريا العشر والسنة الأولى جامعي. المواد مرتبة حسب المعامل.
- **3 أزرار سحرية لكل درس:**
  1. **ملخص الـ 5 دقائق**: ملخص معتمد إن أضافه المحررون، وإلا ملخص بصري يولّده الذكاء الاصطناعي (الأفكار الأساسية، التعاريف، القوانين، نصائح الامتحان، الأخطاء الشائعة) ويُحفظ على الهاتف.
  2. **أفضل الشروحات**: الطلبة يقترحون فيديوهات يوتيوب ويصوّتون لها، ويظهر أفضل 3. التصويت محمي: لا يمكن تضخيم العدّاد إلا بصوتك أنت.
  3. **الحوليات**: كل تمارين البكالوريا التي ورد فيها الدرس، مع الموضوع والحل النموذجي.
- **تقدّم كل مادة** بشريط ونسبة، وحالة لكل درس: لم أبدأ / أراجعه / صعب عليّ / أتقنته.
- **تصفية المحتوى**: اكتب «أريد ملخص درس الموافقات شعبة رياضيات» فيفتح الدرس الصحيح، حتى لو كان من شعبة أخرى، على الزر المطلوب (ملخص، شرح، حوليات). البحث يتجاهل اختلاف الهمزات والتاء المربوطة والتشكيل.
- **خطة اليوم** في الرئيسية: دروس اليوم حسب الأيام المتبقية للامتحان (تاريخه قابل للتعديل)، تقدّم الدروس «الصعبة» والمواد ذات المعامل الكبير والمواد التي نال فيها الطالب علامات ضعيفة عند المصحح الذكي، وتترك آخر أسبوعين للمراجعة العامة.

### 3. مصحح الأستاذ الافتراضي
- صوّر ورقة إجابتك (حتى 4 صفحات، ومعها صورة نص التمرين إن شئت). الصور تُصغَّر وتُضغط على الهاتف قبل الإرسال.
- يُرسَل كل شيء إلى Gemini مع تعليمات مصحح البكالوريا الرسمي (المنهجية الرسمية) ومخطط JSON صارم، فيعود بـ:
  1. العلامة المقدّرة بأرباع النقطة (مثلاً 1.5 / 3)، وإن حدّدت علامة السؤال تُحترم.
  2. نقد المنهجية.
  3. التصحيح خطوة بخطوة (صحيح / ناقص / خطأ) مع التصويب.
  4. الحل النموذجي ونصيحة ختامية مشجّعة.
- التصحيحات تُحفظ في سجل الطالب (بدون الصور)، وتغذّي خطة اليوم.

### 4. غرف التركيز
- غرفة لكل مجموعة مواد (الرياضيات، الفيزياء، العلوم، الفلسفة والأدب، التاريخ والشريعة، اللغات، التكنولوجيا، التسيير، مراجعة حرة)، والغرف المناسبة لشعبتك أولاً.
- **عداد واحد لكل الطلبة**: 25 دقيقة تركيز ثم 5 راحة، تبدأ الدورات كل نصف ساعة حسب ساعة الخادم، فيرى الجميع نفس العداد في نفس اللحظة بلا أي خادم إضافي.
- **الحضور المباشر** في Realtime Database: عدد الطلبة في الغرفة ومن كم ولاية. إذا انقطع اتصال طالب يحذفه الخادم وحده.
- بلا دردشة. خلفية صوتية اختيارية: صمت تام، لوفاي هادئ، أو ضجيج بني. المقطعان مولَّدان بالكامل بـ [`tool/generate_ambience.py`](tool/generate_ambience.py)، فلا حقوق لأحد عليهما.

### 5. بنك الصوتيات
- حلقات التاريخ والجغرافيا والعلوم الإسلامية والفلسفة، مع تصفية حسب المادة والمستوى، ومشغّل مصغّر يبقى ظاهراً في كل التبويبات.
- **الحلقات المسجّلة** (من Firestore) تستمر والشاشة مقفلة، مع أزرار التحكم في الإشعار وشاشة القفل.
- **البطاقات المرفقة بالتطبيق** (12 بطاقة: تواريخ الثورة، شخصياتها، الحرب الباردة، الاتحاد الأوروبي، مقاصد الشريعة، الذاكرة، اللغة والفكر…) يقرؤها صوت الهاتف العربي، مع النص لمتابعة القراءة.

## البنية

```
lib/
├── core/
│   ├── ai/          AiClient: Firebase AI Logic، أو مفتاح Gemini للتطوير، أو «غير متاح»
│   ├── audio/       PlaybackService (just_audio + الخلفية + قراءة النص) والمشغّل المصغّر
│   ├── di/          AppDependencies: نسخة Firebase ونسخة تجريبية
│   ├── constants/   الألوان، الثيم، النصوص، الولايات والمستويات والشعب
│   └── utils/       التحقق من البريد وكلمة السر والهاتف الجزائري
├── features/
│   ├── auth/        المرحلة 1
│   ├── syllabus/    المرحلة 2: المنهاج، الدروس، البحث، خطة اليوم
│   ├── grader/      المرحلة 3
│   ├── focus/       المرحلة 4
│   ├── audio_bank/  المرحلة 5
│   └── home/        الواجهة بخمس تبويبات والرئيسية
├── app.dart
└── main.dart        يهيّئ Firebase أو يدخل الوضع التجريبي
```

كل ميزة مقسّمة إلى `domain` (نماذج وواجهات بلا Flutter) و`data` (Firebase ونسخ في الذاكرة) و`presentation` (Cubit/Bloc والصفحات). إدارة الحالة بـ `flutter_bloc`.

## التشغيل

```bash
flutter pub get
flutter run        # وضع تجريبي إلى أن تربط Firebase
flutter test       # 52 اختباراً، منها مسار كامل عبر التبويبات الخمس
```

في **الوضع التجريبي** يعمل كل شيء على الهاتف (شريط ذهبي أسفل الشاشة يوضح ذلك): الحسابات، التقدّم، الفيديوهات، الغرف، البطاقات الصوتية. الذكاء الاصطناعي يحتاج Firebase أو مفتاحاً للتطوير:

```bash
flutter run --dart-define=GEMINI_API_KEY=…            # للتجربة فقط: المفتاح يُستخرج من التطبيق
flutter run --dart-define=GEMINI_MODEL=gemini-3.5-flash   # النموذج الافتراضي
```

## ربط Firebase

1. أنشئ مشروعاً في [console.firebase.google.com](https://console.firebase.google.com) وفعّل:
   - **Authentication ← Email/Password**
   - **Firestore**
   - **Realtime Database** (لحضور غرف التركيز)
   - **AI Logic ← Gemini Developer API** (للملخصات والمصحح؛ لا مفتاح في التطبيق). يُنصح بتفعيل App Check قبل النشر.
2. في هذا المجلد:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure      # يستبدل lib/firebase_options.dart
   firebase deploy --only firestore:rules,database
   ```
3. أعد التشغيل: يختفي الشريط التجريبي.

### المحتوى الذي يضيفه المحررون

المحرر حساب له المطالبة `{admin: true}` (تُضاف بـ Admin SDK). القواعد تمنع غيره من الكتابة هنا.

**`lessons/{lessonId}`** (معرّف الدرس من `curriculum.json`، مثل `bac_math_arith_03` للموافقات):
```json
{
  "summary": "ملخص معتمد، سطر لكل فكرة",
  "summaryPdfUrl": "https://…/resume.pdf",
  "pastPapers": [
    {"year": 2019, "title": "الموضوع الأول · التمرين الثاني",
     "subjectUrl": "https://…/sujet.pdf", "solutionUrl": "https://…/corrige.pdf"}
  ]
}
```

**`audio_tracks/{id}`**:
```json
{"title": "…", "category": "history | geography | islamic | philosophy",
 "levels": ["bac"], "audioUrl": "https://…/episode.mp3", "minutes": 6, "transcript": "…"}
```

أما الفيديوهات (`lessons/{id}/videos/{youtubeId}`) فيضيفها الطلبة من التطبيق.

### المنهاج

[`curriculum.json`](assets/curriculum/curriculum.json) ملف يحرَّر مباشرة: `subjects` (الاسم والأيقونة)، `programs` (الوحدات والدروس بمعرّفاتها)، و`streams` (لكل شعبة: المادة، المعامل، البرامج). الدرس المشترك بين شعبتين يحمل نفس المعرّف فيتشارك الفيديوهات والحوليات. **لا تغيّر معرّف درس موجود**، وأضف الدروس الجديدة بمعرّفات جديدة.

> المعاملات وقوائم الدروس مبنية على المنهاج الرسمي لكنها استرشادية: راجعها مع آخر منشور لوزارة التربية الوطنية، خاصة شعبتي الفنون واللغات والمواد الجامعية التي تختلف بين الجامعات.

## اختبار قواعد الأمان

قواعد [`firestore.rules`](firestore.rules) و[`database.rules.json`](database.rules.json) مختبرة على محاكيات Firebase (يحتاج Node 22 وJava 21):

```bash
cd rules_test && npm ci && npm test
```

تغطي: الملف والتقدّم والتصحيحات لصاحبها فقط، المحتوى المنسّق للمحررين فقط، اقتراح الفيديو بعدّادات صفرية، وعدّادات التصويت التي لا تتحرك إلا بتغيّر صوت المصوّت نفسه في نفس العملية، وحضور الغرف لصاحبه فقط وفي غرفة معروفة.

سير العمل [`.github/workflows/studybuddy.yml`](../.github/workflows/studybuddy.yml) يشغّل التحليل والاختبارات واختبار القواعد ويبني نسخة Android عند كل تغيير.

## ملاحظات

- `google_fonts` مثبّت على `^8`: النسخة 9 تعتمد على حزمة `material_ui` المنفصلة ولا تتوافق مع Material المدمج في Flutter 3.47.
- قراءة البطاقات تحتاج صوتاً عربياً في «تحويل النص إلى كلام» على الهاتف، والتطبيق ينبّه إن لم يجده. هذه البطاقات لا تستمر والشاشة مقفلة؛ الحلقات المسجّلة تستمر.
- عدّاد الغرف يقرأ قائمة الحاضرين كاملة، وهذا مناسب لمئات الطلبة في الغرفة. للآلاف يُستحسن عدّاد تحدّثه Cloud Function.
- قائمة الولايات هي الـ 58 الرسمية؛ إذا اعتُمد تقسيم إداري جديد فحدّث `core/constants/algeria_data.dart` وحدّ `wilaya` في القواعد.
